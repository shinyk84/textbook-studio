기존 단계 중 불필요한 부분을 줄여 5단계로 다시 짰고, 그 과정에서 4개 출판사의 교과서·지도서 자료를 더 폭넓게 살펴 실제 교과서가 쓰는 집필 방식을 초고 생성에 반영했다.

01 / 05

결과물 비교

구분이전지금
문장 같은 조건이면 항상 같은 문장 → 매번 새로 집필돼 문장이 달라짐
절 구성 소단원과 무관하게 같은 제목 4개 반복 → 소단원마다 다른 제목 — 예: "도구가 만들어 낸 경기의 언어"
단원 마무리 본문과 똑같은 설명글 → 복습·체크리스트·활동 중심 — 예: "나의 배움 점검표"
실기형 이론형과 내용 구분이 거의 없음 → 역할 수행·참여 활동 중심으로 차별화
삽화 내용과 무관한 고정 틀 → 내용에 맞는 이미지를 직접 생성(선택 사항)
02 / 05

개발 중 발견한 주요 오류

  1. 전체 스타일 3종 중 2종이 실제로는 같은 결과로 나옴
  2. 절 제목이 내용과 무관하게 항상 같은 틀로 고정됨
  3. "실기형"을 골라도 "이론형"과 똑같이 생성됨
  4. 절 개수가 늘어나면서 일부 절 내용이 화면에서 빠짐
  5. 생성한 삽화가 다른 컴퓨터에서는 보이지 않음

자료가 최종 원고까지 전달되는 여러 단계에서 값이 누락·왜곡되던 지점들 — 모두 확인 후 수정 완료.

03 / 05

아직 남은 과제

  • 종목·스타일·유형 전체 조합은 다 확인하지 못함(대표 사례 위주로 검토)
  • 모의심사(5단계) 미실행 — AI 초고 자체를 심사하는 기능이 아니라, 편집자가 수정을 마친 최종본을 올려 심사받는 용도. 이 흐름은 아직 검증 전
  • 휴대폰 화면에서 일부가 잘려 보이는 문제 — 수정 중
  • PPT로 내보내면 화면 배치와 100% 같지는 않음
04 / 05

180쪽 전체 1회 생성 비용

$20–30내외 · 근사치

펼침면 90개 기준 — 텍스트 90회 생성 + 삽화 평균 3장(총 약 270장). 실제 시세: 이미지 장당 3~8센트, 텍스트는 백만 토큰당 입력 $5 · 출력 $30(최상위 등급 기준).

결과가 만족스러울 때까지 보통 여러 번 다시 만들게 됨 — 2~3회 재생성 시 비용도 2~3배 이상.

3자 집계 기준 · 발표 전 실제 청구 내역 재확인 권장 — WaveSpeed, Unifically, Finout
