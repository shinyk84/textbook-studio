# 스포츠 문화 종목 적용 규칙

## 전처리 교과서 목차에서 확인한 패턴

종목은 모든 단원에 동일하게 적용되지 않는다. 개념·역사·철학에서는 종목을 사용하지 않거나 여러 종목을 사례로 비교하고, 시설·규칙·기능·대회 운영에서는 하나의 주 종목을 중심으로 전개한다.

- 2009 YBM: 축구·농구·야구·배구가 각각 독립 단원이 되고 운영·역할·전략을 전개한다.
- 2022 지학사·천재: 개념 영역과 종목별 실천 영역을 분리한다.
- 2022 미래엔: 육상·보디빌딩·태권도·골프·스키를 실천 단원으로 두고 별도 종목 페이지를 추가한다.
- 2022 동아: 개념 설명에서는 여러 종목을 사례로 쓰고 대회 운영에서는 특정 종목을 중심으로 구성한다.

## 스튜디오 적용 방식

- `종목 없음`: 특정 종목 없이 개념과 문화적 맥락을 설명한다.
- `여러 종목 사례`: 복수 종목을 비교 자료로 사용하고 목차명이나 시설·동작 체제를 한 종목으로 고정하지 않는다.
- `주 종목 중심`: 한 종목만 선택하여 목차, 시설, 규칙, 동작, 전술과 운영에 일관되게 반영한다.

상단 종목 선택은 책에서 사용할 수 있는 후보 목록이다. 후보 종목을 모든 소단원에 자동 배정하지 않는다. 전처리 기반 초기 목차에는 사용 방식과 종목을 추천하지만, 사용자가 수정한 값은 자동으로 덮어쓰지 않는다. 제목을 수정한 뒤 `현재 목차명으로 다시 추천`을 눌렀을 때만 해당 소단원의 추천을 다시 계산한다. 초고 생성기는 저장된 최신 사용자 값을 우선한다.
