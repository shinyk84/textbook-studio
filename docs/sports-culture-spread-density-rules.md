# 스포츠 문화 펼침면 분량·반복 방지 기준

## 전처리 교과서 실측

전처리한 스포츠 문화 교과서 5종에서 표지·간지와 저밀도 페이지를 제외하고 펼침면의 텍스트를 비교했다.

| 자료 | 펼침면 글자 수 중앙값 | 25~75% 범위 |
|---|---:|---:|
| 2009 개정 YBM | 1,693자 | 1,450~1,976자 |
| 2022 개정 천재교과서 | 1,333자 | 1,128~1,454자 |
| 2022 개정 동아출판 | 1,440자 | 1,047~1,845자 |
| 2022 개정 지학사 | 1,417자 | 1,268~1,580자 |
| 2022 개정 미래엔 | 1,621자 | 1,478~1,810자 |

내용 유형별 중앙값은 이론형 약 1,457자, 실기형 약 1,592자, 혼합형 약 1,583자였다. 이미지·활동지 비중에 따른 편차가 있으므로 글자 수만으로 품질을 판정하지 않는다.

## 스튜디오 적용 규칙

- 펼침면마다 고유한 내용 역할을 부여한다. 이론형은 개념·역사·철학·사회 쟁점·자료 비평·현대 확장, 실기형은 종목 문화·시설과 안전·규칙·기능·전술과 역할·운영과 평가로 전개한다.
- 분량을 늘릴 때 공통 문장을 반복하지 않는다. 해당 펼침면 역할에 필요한 사실, 관점, 사례, 수행 절차를 추가한다.
- 생성 후 한 원고 안에서 35자 이상 동일 문장을 검사하고 중복 문장을 제거한다.
- 본문 문단만 최소 1,400자 이상을 기본 하한으로 삼는다. 제목·목표·캡션·활동 지시를 더한 전체 정보량은 실측 중앙값 범위와 비교한다.
- 같은 소단원 안에서도 펼침면 제목, 핵심 질문, 자료 유형, 학생 과제, 지도서 발문을 각각 다르게 구성한다.
- 글자 수 충족과 별개로 성취기준 근거, 선택 종목 정보, 개념의 정확성, 수행 절차의 실행 가능성을 검토한다.

## 단순화한 초고 생성 흐름

기존의 체제안 3개 비교·승인 방식은 스포츠 문화에서 사용하지 않는다. 전체 스타일과 실제 페이지 체제를 분리하여 다음 세 값으로 초고 구성을 결정한다.

1. 전체 스타일 슬라이더: 안정·정석형에서 참신·활동형까지 책 전체의 설명량, 활동, 질문, 사례와 시각 자료 방향을 조정한다.
2. 소단원 유형: 이론형 또는 실기형을 소단원마다 저장한다. 이론형에는 `활동 포함`, 실기형에는 `개념 설명 포함`을 선택할 수 있다.
3. 페이지 역할: 일반 소단원, 대단원 도입, 대단원 마무리, 읽을거리·진로·안전·문화 비평·프로젝트·수행평가 특별 페이지를 구분한다.

초기에는 이론형과 실기형을 각각 한 개씩 생성하여 확인하고, 설정이 적절하면 소단원을 다중 선택해 같은 전체 스타일로 일괄 생성한다. 대단원 도입과 마무리는 대단원마다 자동으로 생성 대상 후보에 포함하고, 특별 페이지는 필요한 위치와 유형만 추가한다.
