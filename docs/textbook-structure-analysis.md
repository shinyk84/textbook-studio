## 0. 요약

- **대단원 수 = 교육과정 영역 수.** 2015는 5개 영역(건강·도전·경쟁·표현·안전) → 학년마다 5단원, 2022는 3개 영역(운동·스포츠·표현) → 학년마다 3단원. 조사한 모든 출판사가 예외 없이 영역 1개를 대단원 1개로 만들고 교육과정 영역 순서대로 배열했다(검정 편찬 유의점 "단원은 가급적 영역 순서대로").
- **바뀌지 않은 것**: 학년당 102차시(204시간/학년군), 교과서 본문+부록 120쪽 ±10%(앞부분 10쪽 이내 별도), 2쪽 펼침면 1개 = 1~3차시(차시당 1.16~1.27쪽), 대단원 도입 1차시·마무리 1차시, 지도서는 교과서 펼침면 1개당 2~4쪽(교과서의 약 2배)과 총론 40~60쪽.
- **바뀐 것**: 영역별 비중. 2015는 다섯 영역이 12~30차시로 비교적 고르게 나뉘었고, 2022는 스포츠가 50~63차시(약 57%)를 차지하고 운동·표현이 각 20~26차시다. 성취기준 수 비율(스포츠 43~46%)보다 차시 비중이 크다 — 실기 중심 영역이 남는 시간을 흡수한다.
- **출판사 차이는 구조보다 체제·장치에서 난다.** 단원 수·총 차시는 같고, 영역별 차시(예: 2022 운동 20~30), 중단원 수(2~4), 단원 도입·마무리 방식, 확장 코너, 캐릭터·세계관, 지도서의 과정안·평가지 위치가 다르다. 금성(5·6)과 아이스크림은 영역별 3권 분권을 택했다.
- **차기 개정 대응**: 위 불변 규칙을 상수로, 영역·성취기준 수를 입력으로 받아 단원·차시·쪽수를 제안하는 엔진을 만들었다(`scripts/propose_book_structure.py`). 2015 실측만으로 2022 책을, 2022 실측만으로 2015 책을 예측하는 교차 백테스트에서 영역별 차시 평균 오차 3.1차시였다. 편집자는 이 제안과 실측 범위를 보고 최종 결정한다.

### 2-3. 단원 내부 흐름(공통 골격)

모든 출판사가 같은 골격을 쓰고, 이름과 장치만 다르다.

```
대단원 표지·도입 (2~6쪽, 1차시)  : 질문·이야기·학습 목표·사전 진단
  └ 중단원 × 2~4
       └ 주제 펼침면 (2쪽 = 1~3차시) × n : 생각 열기 → 활동 1~3 → 확인/스스로 평가
       └ (선택) 대회·게임 적용 펼침면
  확장 코너 (1~4쪽, 대개 차시 미배정) : 융합·디지털·시민·생활 속 체육
대단원 마무리 (1~6쪽, 1차시)       : 퀴즈형 확인 + 지식·기능·태도 자기 평가
```

- 5·6학년 스포츠는 종목마다 "기본 기능 → 기본 전략 → 게임" 3단 펼침면이 굳어진다(2015 경쟁, 2022 전략형 모두).
- 3·4학년은 1쪽 주제, 놀이형 장치(붙임딱지 등)가 많고, 5·6학년은 2쪽 단위 고정, 성찰·다짐·프로젝트가 늘어난다.

## 4. 개정이 바뀌어도 유지되는 규칙과 바뀌는 변수

차기 개정 책을 설계할 때 **상수**는 그대로 쓰고, **변수**만 새 교육과정에서 다시 계산한다.

| 구분 | 항목 | 값(실측·기준) |
|---|---|---|
| 상수 | 학년당 차시 | 102 (34주 × 3) |
| 상수 | 교과서 분량 | 본문+부록 108~132쪽 + 앞부분 ≤10쪽 (검정기준 120쪽 ±10%) |
| 상수 | 펼침면 단위 | 2쪽 = 1~3차시, 차시당 1.16~1.27쪽 |
| 상수 | 단원 틀 | 도입 1차시 + 중단원 2~4 + 확장 코너 + 마무리 1차시 |
| 상수 | 지도서 | 총론 40~60쪽 + 교과서 펼침면당 2~4쪽 + 과정안·평가지 + 부록 |
| 상수 | 단원 순서 | 교육과정 영역 순서 |
| 변수 | 대단원 수 | = 영역 수 |
| 변수 | 영역별 차시 | 성취기준 수 × 영역 유형(실기 중심 영역이 나머지를 흡수) |

| 변수 | 학년 분할 | 지식·기능 기준 분할 / 태도 기준 반복 / 5·6 공유 영역은 종목 교체 |
| 출판사 선택 | 분권 여부, 영역별 비중 ±5~10차시, 확장 코너, 캐릭터·세계관, 지도서 과정안 위치 | |

## 5. 차기 개정(2028년 이후) 구조 제안 방법

### 5-1. 제안 엔진

`scripts/propose_book_structure.py`가 교육과정 사양(영역, 영역 유형, 성취기준 수, 시수)을 받아 단원·차시·쪽수·중단원·펼침면 수와 지도서 쪽수를 제안한다. 근거 수치는 `book_structure_baselines.json`(출판사·학년별 실측 42종: 2015 14종, 2022 28종)이다.

차시 배분은 두 모형의 평균(`blend`)을 쓴다.

- `share`: 성취기준 비중 × 영역 유형 강도(실측 차시 비중 ÷ 성취기준 비중)
- `anchor`: 운동·표현·안전 같은 비실기 영역은 "성취기준당 차시" 실측값으로 고정하고, 남는 차시를 스포츠(기술·전략형) 영역이 흡수

쪽수는 영역 유형별 차시당 쪽수 실측 중앙값으로 계산해 짝수로 맞추고, 본문+부록이 132쪽을 넘으면 큰 단원부터 2쪽씩 줄인다.

**교차 백테스트**(한 개정의 실측만으로 다른 개정의 실제 책을 예측, `--backtest`):

| 모형 | 영역별 차시 평균 오차 | 최대 오차 |
|---|---|---|
| share | 5.5 | 13.5 |
| anchor | 4.8 | 7 |
| **blend(기본)** | **3.1** | 8.5 |

예: 2015 실측만으로 2022 3~4학년군을 예측하면 운동 29 / 스포츠 55 / 표현 18 (같은 학년군 실제 중앙값 20.5 / 58 / 20). 영역 체계가 바뀐 개정을 넘어서도 출판사 간 편차(±5~10차시) 안에 대체로 들어오지만, 운동처럼 과대 예측되는 영역이 있으므로 **제안값은 출발점이고 결정은 편집자가 한다.**

### 5-2. 시나리오별 제안 (가정 — 공식 고시가 아님)

차기 교육과정 내용은 아직 확정되지 않았다. 2009→2015→2022 추세(영역 축소, 성취기준 감축, 안전·디지털·생태 강화)를 바탕으로 세 가지 가정을 돌린 결과다. 사양 파일은 [structure-analysis/scenarios/](structure-analysis/scenarios/)에 있다.

| 시나리오 | 단원 | 차시 | 교과서 쪽수(본문) | 지도서 |
|---|---|---|---|---|
| S1 3영역 유지·성취기준 20개(3~4) | 운동 · 스포츠(중단원 3~4) · 표현 | 21 / 63 / 18 | 28 / 70 / 24 = 122 (+부록 6, 앞 8 → 136쪽) | 약 326쪽(260~393) |
| S2 안전·생태 분리 4영역(3~4) | 운동 · 스포츠 · 표현 · 안전·생태 | 19 / 55 / 17 / 11 | 26 / 60 / 22 / 16 = 124 (→ 138쪽) | 약 330쪽 |
| S3 3영역 + 영역 통합 프로젝트(5~6) | 운동 · 스포츠 · 표현 · 프로젝트 | 19 / 60 / 17 / 6 | 26 / 66 / 22 / 4 = 118 (→ 132쪽) | 약 318쪽 |

고시가 나오면 실제 영역·성취기준 수로 사양 파일만 바꿔 다시 돌린다.

```
python scripts/propose_book_structure.py --spec docs/structure-analysis/scenarios/next_s1_3areas.json
python scripts/propose_book_structure.py --rev 2022 --band 5-6   # 실측과 나란히 비교
python scripts/propose_book_structure.py --backtest
```

### 5-3. 편집자가 결정해야 하는 항목

엔진이 범위만 주고 편집자가 정하는 항목:

1. 영역별 차시(제안값 ± 실측 범위 안에서) — 예: 운동을 금성·미래엔처럼 25~30으로 키울지
2. 분권 여부(단권 vs 영역별 3권), 프로젝트 단원 여부
3. 중단원 구성(하위 유형별 vs 종목별)과 종목 선정
4. 학년 분할 방식(성취기준 분할 vs 공유 + 종목 교체)
5. 확장 코너·캐릭터·세계관 등 체제 — 참고 패턴은 비교용이며 타사 문장·디자인을 복제하지 않는다(`ANALYSIS_RULES.md` 1장)

## 6. 통합 제작 도구 설계

[integrated-kit-design.md](integrated-kit-design.md)의 L0~L4 구조(책 프로필 → 콘텐츠 원장 → 생성기 → 인디자인 왕복 → 영향 분석)에 **구조 설계 단계**를 L0과 L1 사이에 넣는다.

```
L0 교육과정 입력 ─ 고시 PDF 전처리 → 영역·성취기준·시수 추출 → 편집자 확인
      │
L0.5 구조 설계 엔진 ─ 실측 기준선 + 검정 분량 + 제안 모형
      │   → 대안 2~3개(표준형 / 실기 강화형 / 프로젝트형) 와 실측 범위·유사 출판사
      │   → 편집자 확정: 단원·중단원·차시·쪽 예산·학년 분할
      ▼
L1 콘텐츠 원장 골격 생성 ─ 책 › 대단원 › 중단원 › 차시 › 펼침면 › 요소(빈 자리)
      │   쪽 예산·차시 번호·성취기준 연결이 미리 채워진 상태
      ▼
L2 초안 생성 ─ 펼침면 단위 원고 + 삽화 발주(개수·크기·배치) + 지도서 파생(펼침면당 2~4쪽)
      │          + 활동지·평가지·과정안·영상 대본
L3 조판 ─ ICML/IDML 패키지 → 인디자인 → 회수 → 쪽 대응표
L4 수정 ─ 의견 → 수정안 → 승인 → 수정조판, 영향 알림·전파
```

### 6-1. 구조 설계 화면(신규)

| 영역 | 내용 |
|---|---|
| 입력 | 개정·학년군·학년, 영역(이름·유형·성취기준 목록), 시수, 분량 기준(120 ±10%, 앞 10쪽), 분권·프로젝트 옵션 |
| 제안 | 영역별 차시·쪽수·중단원·펼침면 수, 각 값 옆에 실측 범위와 가장 가까운 출판사 사례(예: "스포츠 58차시 — 실측 50~63, 비상·천재 유사") |
| 학년 분할 | 성취기준마다 3/4(또는 5/6) 배치 추천 — 2022 실측 규칙(지식·기능 분할, 태도 반복, 5·6 종목 교체)을 기본값으로 |
| 검증 | 102차시 합계, 본문+부록 108~132쪽, 모든 성취기준 배치, 영역 순서, 단원 쪽수 짝수, 학년 간 중복 |
| 확정 | 확정안을 책 프로필과 원장 골격으로 저장(버전·승인 기록) |

### 6-2. 원장 골격에 미리 들어가는 값

- 차시: 번호(n/m), 성취기준 코드, 교과서 쪽 범위(예산), 중단원
- 펼침면: 유형(도입·주제·적용 게임·확장·마무리), 담당 차시(1~3), 쪽 예산 2
- 지도서: 펼침면별 지도면 2~4쪽 자리, 중단원별 과정안·평가지 자리, 총론의 연간 계획표(원장에서 자동 생성)

이 골격이 있으면 초안 생성은 "빈 펼침면 채우기"가 되고, 조판 단계의 쪽 대응표·영향 알림이 처음부터 같은 ID를 쓴다.
