1. **단원 시작(대단원 표지, 2쪽)**: 영역명 + 중단원 목록 + 캐릭터 이야기(3·4학년 튼튼이/사총사, 5·6학년은 상황 만화). 예: pe3 phys 9, 99.
2. **이야기로 시작해 볼까요?(2~4쪽, 1~2차시)**: 「~을 알아볼까요?」 도입 차시. 영역 개념(운동과 체력, 스포츠 유형, 표현 유형) 탐색.
3. **중단원(2~3개)**: 중단원 첫 쪽에 번호+제목. 이후 **제재 = 2쪽 펼침**이 반복.
   - 왼쪽(짝수 쪽): 발문(「~할까요?」, 예: "걷기와 달리기는 어떻게 다를까요?") → 제재명 → 개념 설명 → 활동 1(그림·사진, 「활동 방법」 번호 목록).
   - 오른쪽(홀수 쪽): 활동 2(3) 게임(방법·승패) → 측면 박스(안전, 스마트 기기 활용, 더 알아보기, 활동지/붙임딱지 활용) → **확인해요**(● 자기 점검 질문 1~2개).
   - 쪽 하단 러닝 푸터: 짝수 쪽 「n. 영역명」, 홀수 쪽 「중단원명」 → 경계 검출에 유용.
4. **특집 코너(2쪽, 1차시)**: 각 대단원 끝에 1개, 상단에 「~ 능력과 ~을/를 길러요.」 역량 태그.
5. **배운 내용을 정리해요(2쪽, 1차시)**: 4개 하위 코너 고정.

- 차시당 쪽수: 3학년 본문 120쪽/96차시 ≈ 1.25쪽, 5학년 120쪽/102차시 ≈ 1.18쪽, 6학년 118쪽/102 ≈ 1.16쪽. 운동 단원은 2쪽=1차시, 스포츠는 2쪽=2차시(일부 3), 표현은 2쪽=1~2차시.

### 11-2. 5~6학년군 ([6체01-01~06], [6체02-01~12], [6체03-01~08])
| 영역 | 5학년(천재 / 동아) | 6학년(천재 / 동아) |
|---|---|---|
| 운동 | 건강 체력 + 성장(성 건강·감정·관계): 천재 01-01·02·05(+03·06) / 동아 ➊ 01-01·02·05, ➋ 01-03·04·06 | 운동 체력 + 안전: 천재 01-01·02·05, 01-04 / 동아 ➊ 01-01·02·05, ➋ 01-04 |

| 표현 | 천재: 스포츠·전통·현대 3종 모두(03-02~07) / **동아: 스포츠 표현 + 우리나라 전통 표현(03-01~05·08)** | 천재: 3종 모두(03-02~07) / **동아: 외국의 전통 표현 + 현대 표현(03-01·04~08)** |

→ 운동: 두 출판사 모두 **5학년 = 건강 체력·성장 발달(6체01-01·02·03·05·06)**, **6학년 = 운동 체력·안전(6체01-01·02·04·05)**.
→ 스포츠: 두 학년이 같은 성취기준 묶음을 반복하고 **하위 유형별 종목을 학년 간 분배**(예: 동아 5 = 기록·표적·동작형, 6 = 기록·투기형; 천재 5 = 기록·동작·투기, 6 = 기록·표적·동작·투기).
→ 표현: **천재는 학년마다 3유형 모두**, **동아는 학년별 2유형씩 분할**(전통 표현을 5학년 국내 / 6학년 외국으로 나눔).
