## 0. 핵심 결론 (요약)

1. **권(분권) = 대영역 1개 = 대단원 1개.** 두 출판사 모두 1권 = 1. 운동, 2권 = 2. 스포츠, 3권 = 3. 표현이다. 금성 3·4학년은 단권(118쪽)이지만 내부 구성은 똑같이 운동 → 스포츠 → 표현 3개 대단원이다.
2. **분권해도 쪽 번호는 이어진다.** 교과서(예: 금성 5학년 6–37 / 38–97 / 98–125쪽, 아이스크림 3학년 6–33 / 34–99 / 100–127쪽)와 지도서(예: 아이스크림 3학년 54–99 / 100–217 / 218–291쪽) 모두 그렇다. 하나의 책을 영역 경계에서 물리적으로 나눈 구조다.
3. **권 분량은 고르지 않다.** 스포츠 권이 운동·표현 권의 약 2~2.4배다(예: 아이스크림 5학년 28 / 68 / 28쪽). 무게를 똑같이 나누려고 분권한 것은 아니다. 영역 단위로 나눠 **필요한 권만 들고 다니게 하고, 학교가 영역 순서를 자율로 짜게 하려는 설계**로 보인다(추정). 4절 참조.
4. **차시 배분(학년당 102차시 = 주 3시간 × 34주)**
   - 금성: 운동 26~30 / 스포츠 50~54 / 표현 22~26
   - 아이스크림: 운동 20~22 / 스포츠 59~62 / 표현 20~21

   두 출판사 모두 스포츠에 50~60%를 배정해, 성취기준 수 비율(스포츠 43~46%)보다 스포츠 비중이 크다.
5. **지도서 비율**은 교과서 1쪽당 지도서 약 2쪽이다(금성 1.8~2.2, 아이스크림 본문 1.4~1.8). 제공된 지도서 PDF에는 **총론이 없고 각론만 있다**(금성 각론 66쪽·84쪽부터, 아이스크림 54쪽·56쪽부터 시작).

- **과정안·평가지:** 3권 부록에 중단원당 1세트(과정안 2쪽 + 수행 평가 활동지 1~2쪽)가 있다. 3·4학년 7세트(운동 2 + 스포츠 3 + 표현 2), 5·6학년 8세트(2 + 3 + 3).
  - 과정안 항목: 창의 인성 요소, 신체활동 역량, 수업 모형(예: 직접 교수 모형), 학습 집단, 단계별 시간(5-3 p.45)

### 2-6. 아이스크림 고유 특징

- 영역 전체를 하나의 차시 번호로 매긴다(1/62 … 62/62). 대단원 도입은 3·4학년에서 차시 '–', 5·6학년에서 1차시로 계산한다.
- 3·4학년 운동은 '1쪽 = 1차시' 압축형이다. 학년마다 '체육이 만드는 세상'(AI 춤, 착용 기기, 운동 로봇, 스포츠 직업)으로 디지털·진로를 연계한다.
- 5·6학년은 **스포츠 3유형과 표현 3유형(스포츠·전통·현대)을 두 학년 모두에서 다루는 나선형 구성**이다. 금성처럼 학년별로 유형을 나누지 않고, 종목만 바꾼다.
- 전략형 종목은 '기본 기능 → 기본 전략 → 배려/소통/협력하며 게임'의 3단계로 짜고, 뉴스포츠(피클볼·추크볼·플로어볼)를 넣었다.
- 지도서는 '지도서 쪽수'를 계획표에 함께 적는다. 과정안과 평가지는 3권 부록에 모았다.
- 오류 관찰: 5-1 지도서 p.2가 운동 성취기준을 '[6체02-01]~[6체02-06]'으로 표기했다(운동은 6체01이어야 함, 오기). 6-1에서는 6체01로 바르게 적었다.

## 4. 분권 이유에 대한 해석 (추정)

1. **권 = 영역 = 대단원 = 학기·계절 운영 단위.** 두 출판사 모두 영역 경계에서만 권을 나눈다. 학교 교육과정에 따라 영역 순서를 바꾸거나 계절에 맞춰 운영할 때(수영·스키·스케이트 등) 해당 권만 쓰게 하려는 것으로 보인다.
2. **무게·휴대성.** 단권 118~124쪽을 28~68쪽 3권으로 나누면 한 권 무게가 1/4~1/2로 준다. 실기 교과라 운동장이나 체육관에 들고 나가기 쉽다. 다만 권 분량이 영역 크기를 따라 2배 넘게 차이 나므로, 무게를 똑같이 나누는 것이 주목적은 아니다.
3. **개발 시기 차이.** 금성은 2024 적용인 3·4학년을 단권으로, 2025 적용인 5·6학년을 분권으로 냈다. 개발 과정에서 분권 전략을 채택했을 가능성이 있다.
4. **연속 쪽 매김.** 부록(131쪽 등)과 지도서 쪽 참조가 권을 넘나들어도 쪽 번호가 하나로 유지되도록 한 설계다. 대신 아이스크림은 과정안·평가 부록을 3권 지도서에만 실어, 1·2권 지도서만으로는 그 영역의 평가 자료가 완결되지 않는다.
