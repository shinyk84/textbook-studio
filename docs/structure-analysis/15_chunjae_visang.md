### 1-5. 단원 내부 흐름(천재)

**3·4학년(단원당 약 18–24쪽)**
1. **단원 표지 펼침면(2쪽)**: 큰 삽화, 단원명, 소단원 ①②, 「이 단원을 배우면」 학습 목표 3~4개. 예: 3학년 p.6–7.
2. **영역 도입 펼침면(2쪽, 1차시)**: "○○은 어떻게 할까요?"라는 질문으로 시작한다. ❶무엇을 배울지 알아봐요, ❷어떤 활동을 하는지 알아봐요. 이어서 「이렇게 해요」에서 그 영역의 역량 3단계를 안내한다. 예: 3학년 p.8–9, p.32–33.
   - 역량 3단계: 건강은 평가해요→계획하고 관리해요→실천해요, 도전은 시도해요→분석해요→연습하고 극복해요, 경쟁은 분석해요→의사소통해요→협력하며 경기해요, 표현은 탐구해요→신체 표현해요→감상하고 느낌을 나눠요, 안전은 같은 틀(추정).
3. **활동 펼침면 반복**: 보통 펼침면 1개(2쪽)가 차시명 1개이고 1~3차시에 해당한다. 경쟁 단원은 차시명 1개가 2쪽이며 2~3차시이다.
   - 상단 띠 제목: 소단원 번호와 차시명.
   - 「오늘의 주인공」: 질문형 동기 유발.
   - 활동 유형 꼬리표: 탐구하기, 실천하기, 조사하기, 점검하기, 전략 세우기, 함께하기.
   - 「방법」「게임 방법」「활동 방법」 상자, 「안전」, 「내가 채우는 말풍선」, 「창의+」, 「게임 더 하기 / 더 해 보기」, 「활동지 활용하기(○쪽)」.
4. **소단원 끝 「이렇게 해요」**: 영역 역량 3단계에 맞춘 자기 기록 칸이다. 예: 도전의 나의 기록, 목표 기록, 잘되는 점, 노력할 점. p.37, p.41, p.47처럼 차시마다 붙는 경우도 있다.
5. **단원 마무리 펼침면(2쪽, 1차시)**: 확인해요(낱말 퀴즈·게임), 평가해요(○× 판단), 쉬어 가요(읽을거리), 더 해 봐요(실천 확인)의 4개 코너로 되어 있다. 문제를 마치면 「왕관 붙임 딱지」를 붙인다(133쪽 안내). 예: 3학년 p.28–29.
- 쪽당 차시: 3학년 본문 112쪽/102차시 ≈ 1.1쪽, 4학년도 같다. 단원별로는 표현·안전이 1.3~1.5쪽/차시이고, 경쟁(17차시를 12쪽에)은 0.7쪽/차시이다.

**5학년(단원당 18–28쪽): 3·4학년과 다른 점**
- 단원 표지 오른쪽 위에 「생각을 열어요」가 붙는다. Big Idea형 핵심 질문으로, 예를 들어 p.7 "우리는 어떻게 성장하는가?", p.3 견본의 "왜 우리는 자기 영역에서 책임을 다해야 하는가?"가 있다.

### 3-6. 단원 내부 흐름(비상, 단원당 20–32쪽)
1. **단원 시작하기(표지 2쪽)**: 단원 번호, 영역명, 단원명, 소단원 목록, 「○○을 배우면」 목표.
   - 3·4학년은 p.8–9 표지에 목표를 넣는다.
   - 5·6학년은 표지에 교과 역량 육각형 아이콘(건강 관리, 신체 수련, 경기 수행, 신체 표현)과 「이 단원을 배우면」을 둔다(5학년 p.9, 6학년 p.38–39 이미지).
2. **단원 둘러보기(2쪽, 1차시)**: 「○○이 궁금해요」. 만화형 삽화와 함께 「배울 내용 소개」, 「인성 가치 소개」(교사용)가 있다.
   - **「내 수준 알아보기」(경험·기능·태도 3칸, 이모티콘 3단계 자기 진단)**: 5·6학년에서는 「나의 수준을 알아볼까요?」라는 이름이 된다.
   - 「이렇게 공부할게요」 다짐 쓰기(p.10–11).
3. **단원 학습하기**: 소단원 띠 제목(번호 + "땅에서 빠르게 달려요" 같은 서술형 제목) 아래에 학습 주제(★ 아이콘 + 제목)를 1~2쪽 단위로 반복한다. 학습 주제 안에서 활동 ①②③이 번호로 이어진다.
   - 영역별 기록 틀:
     - 도전: 재어 보기(1회·2회 기록) → 분석하기 → 도전하기. 3학년 p.37, 4학년의 확인하기·분석하기·도전하기(성공/실패 체크), 5·6학년 「나의 도전 기록지」.
     - 경쟁: 기능 더하기, 전략 탐색(공격/수비).
   - 소단원 끝 학습 주제에 「평가 내용」 표(자기·동료 평가)가 붙는다. 「평가하기·비교하기」로 처음 기록과 비교하는 경우도 있다(3학년 p.39, p.43).
   - 학습 주제마다 하단에 「정리하기」가 있다.
4. **지식 톡톡, 창의 쑥쑥!(2쪽)**: 타 교과(과학, 사회, 국어)와 체육을 잇는 「지식 더하기」 읽을거리와 「창의 활동하기」. 차시에는 넣지 않는다.
5. **단원 마무리(2쪽, 1차시)**: 왼쪽은 「배운 내용 정리하기」 게임형 문항(○× 길 통과, 십자말풀이, 퍼즐), 오른쪽은 「스스로 평가하기」(평가 내용, '○○'의 가치 이해하기, 그림 상황 판단).
- 쪽당 차시: 3학년 126쪽/102 ≈ 1.24쪽, 6학년 126쪽/100 ≈ 1.26쪽. ★3짜리 주제도 보통 2쪽이므로 쪽수와 차시가 꼭 비례하지는 않는다.

## 4. 출판사별 시그니처 특징

**천재교과서**
- 영역마다 고정된 「이렇게 해요」 교과 역량 3단계 루브릭이 도입, 차시, 소단원 끝에서 되풀이된다. 역량 중심 설계가 가장 뚜렷하다.
- 단원 표지 다음에 영역 도입 1차시(펼침면)를 두고, 끝에 마무리 1차시를 둔다. 3·4학년 마무리는 확인해요, 평가해요, 쉬어 가요, 더 해 봐요의 4코너에 「왕관 붙임 딱지」 보상을 붙인다.
- 「오늘의 주인공」, 「내가 채우는 말풍선」, 「창의+」, 「게임 더 하기」로 차시마다 확장과 창의를 덧붙인다. 권말 활동지는 3·4학년 10쪽, 5학년 6쪽이고 「찾아보기」가 있다.
- 5학년부터 Big Idea형 「생각을 열어요」, 인성 읽을거리 「생각을 길러요」, 「나의 다짐 글」이 들어와 개념적이고 성찰적인 어조가 강해진다.
- 실사 사진과 만화 캐릭터를 함께 쓴다. 연간 계획 예시에서 안전 단원을 3월에 먼저 배치한다.
- 지도서는 수업 모형 6종 견본 과정안을 싣는다. 차시마다 「궁금해요–해봐요–탐구해요」 발문 흐름과 수준별지도, 장애 학생지도, 창의·융합, 역량 기르기 코너가 있고, 대단원마다 80분 블록 과정안을 둔다.

**비상교육(손준구)**
- 학습량을 ★(40분) 아이콘으로 표시해 학생 교과서만 보고도 차시를 알 수 있다. 3학년 PDF는 교사용 교과서 주석(N/M차시, 동기 유발, 지도 point, 안전 point, 인성 가치 소개)이 겹쳐 있는 판본이다.
- 「○○이 궁금해요」에서 경험·기능·태도 3축으로 자기 수준을 진단하고 마무리에서 다시 스스로 평가한다. 진단에서 평가로 이어지는 순환 구조이다.
- 소단원과 학습 주제 제목이 서술형이다(예: "땅에서 빠르게 달려요", "더 멀리 뛰며"). 종목 수가 많다(4학년 영역형 4종목, 6학년 여가 6종목, 표적·투기 3종목).
- 모든 단원에 타 교과 융합 2쪽 「지식 톡톡, 창의 쑥쑥!」을 고정 배치한다.
- 경쟁 단원은 기본 기능 → 공격·수비 전략 → 전략 적용 게임 흐름을 종목마다 똑같이 반복한다. 도전 단원은 기록 → 분석 → 목표 → 대회 흐름이다.
- 캐릭터 학습 도우미(연필·몬스터형)의 원리, 안전, 준비 꼬리표가 있다. 찾아보기와 권말 활동지는 없다(활동은 본문 안에 있음). 단원 쪽수는 천재보다 20~30% 많다.

## 5. 출판사 공통 패턴과 학년군 차이

**공통**
- 5개 영역을 학년마다 1개 단원씩, 영역당 1단원·소단원 2~4개로 구성한다. 단원 순서는 건강 → 도전 → 경쟁 → 표현 → 안전이다. 연간 102차시(34주 × 3)이다.
- 단원 앞에 도입 1차시(질문, 목표, 역량 또는 수준 진단), 뒤에 마무리 1차시(퀴즈형 확인과 자기 평가)를 둔다.
- 차시 배분은 경쟁·도전이 가장 크고(23~26), 표현(17~18), 건강(17~23), 안전(12~17) 순이다.
- 학습은 2쪽 펼침면이 1~3차시를 담는 블록 구조이다. 도전은 기록과 분석, 경쟁은 기능 → 전략 → 게임 순서로 반복된다.

**3·4학년과 5·6학년의 차이**
- 천재
  - 5학년에서 마무리가 2쪽에서 1쪽으로 줄고, 「생각을 길러요」 1쪽이 추가된다.
  - 붙임딱지와 쉬어 가요 같은 놀이형 장치가 빠지고 Big Idea, 다짐 글이 들어온다.
  - 소단원 러닝 푸터가 생기고, 활동지는 10쪽에서 6쪽으로 준다.
  - 지도서의 차시 지도면이 2쪽에서 3쪽으로 늘어난다(지도서/교과서 1.8 → 2.2).
  - 5학년은 차시 번호를 단원 전체 일련번호(1/23 … 23/23)로 매긴다.
- 비상
  - 5·6학년은 소단원이 3개인 단원이 많다(도전, 경쟁, 표현).
  - 학습 주제가 "○○ 익히기 → 전략 → 적용 게임/대회"처럼 정형화된 3~4단으로 굳는다.
  - ★3 주제(80~120분 블록)가 늘어난다.
  - 단원 표지에 교과 역량 육각형 아이콘이 생긴다.
  - 「나의 도전 기록지」, 「전략 탐색」 같은 분석 도구가 고정 코너가 된다.
  - 3·4학년은 학습 주제당 ★1~2가 중심이고 1쪽짜리 주제가 많다(특히 건강과 표현).
- 내용 측면(두 출판사 공통): 3·4학년은 놀이·게임 중심의 기초 기능과 생활 습관을 다룬다. 5·6학년은 종목형 게임(필드·네트), 기록 도전(뜀뛰기·던지기·표적·투기), 성장·성 건강, 응급 처치와 심폐 소생술, 민속춤·창작 표현으로 내용이 넓어진다.
