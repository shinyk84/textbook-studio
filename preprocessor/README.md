# 교과서 자료 전처리기

09·15·22 개정 교육과정, 편찬기준, 교과서, 지도서 원본(PDF·HWP·HWPX)을 넣으면 자동으로 분류·전처리하고, 결과 검증이 끝난 원본은 설정에 따라 그대로 두거나 휴지통으로 보내거나 삭제한다. 결과 형식은 `official-data/processed`와 같아서 스튜디오가 바로 읽는다.

## 실행

- `전처리기.cmd`를 더블클릭한다.
- 또는 파일·폴더를 `전처리기.cmd` 아이콘 위에 끌어다 놓는다.
- 명령행: `python preprocessor\core.py <파일 또는 폴더> --after recycle`
  - `--detect-only`: 분류 결과만 확인
  - `--images light|none`: 이미지 크기 줄이기 / 이미지 없이 텍스트만
  - `--output-dir`: 저장 위치 지정

## 화면 사용 순서

1. **파일 추가** 또는 **폴더 추가**를 누른다. 파일명·폴더명·앞뒤 쪽 본문을 읽어 개정, 학교급, 과목, 학년, 출판사, 종류를 추정한다.
2. 노란 줄은 추정이 불확실한 항목이다. 오른쪽에서 고친 뒤 **수정 내용 적용**을 누르거나, 추정이 맞으면 **추정값대로 확정**을 누른다.
3. **▶ 전처리 시작**을 누른다. 흰 줄(대기)만 순서대로 처리한다.
4. 감시 폴더를 켜 두면, 그 폴더에 복사해 넣은 파일을 복사가 끝나는 대로 자동으로 처리한다(노란 줄은 확인을 기다린다).

## 처리 내용

| 종류 | 결과 |
|---|---|
| 교과서·지도서·부도(PDF) | 쪽별 텍스트와 글상자 위치(`pages.jsonl`), 쪽·펼침면 이미지, 펼침면 모음 이미지, 쪽·펼침면 검색 청크, 펼침면 판정·디자인 요소(`layout.jsonl`, `design_catalog.json`, `images/layout`, `images/assets`) |
| 교육과정·기준·공문(PDF·HWP·HWPX) | 문서 본문(`document.md`), 검색 청크. HWP는 원본 쪽 번호가 없으므로 인용할 때 원본 대조가 필요하다. |

- 글자가 거의 없는 쪽이나 워터마크만 있는 PDF는 Tesseract OCR(한국어)로 보완한다. 한국어 OCR 데이터는 처음 필요할 때 `preprocessor/tessdata`에 자동으로 내려받는다(약 15MB).
- 삽화만 있는 쪽처럼 OCR 결과에 한글이 거의 없으면 원래 텍스트를 유지한다.
- 같은 원본(SHA-256 기준)이 이미 처리되어 있으면 다시 처리하지 않고 "중복"으로 표시한다.
- 결과는 `<문서ID>.partial` 폴더에 만든 뒤, 검증(출력 파일, 쪽수, 이미지, 원본 해시)을 통과해야 최종 이름으로 바뀐다. 검증 전에 원본을 건드리지 않는다.
- 저장 위치에 `_전처리목록.csv`(엑셀로 열 수 있는 전체 목록)가 갱신된다.

## 펼침면·디자인 분석(2.1)

- 인쇄 쪽 번호(PDF 쪽 라벨 → 위/아래 여백 숫자)로 왼쪽(짝수)·오른쪽(홀수) 면을 정해 펼침면 짝을 맞춘다. 표지가 앞에 끼어 있어도 어긋나지 않는다.
- 펼침면마다 `spread`(한 장으로 이어진 디자인)·`facing_pages`(따로 된 두 쪽)·`uncertain`을 판정한다. 근거는 접힘선 양쪽 색이 이어지는 비율과 접힘선에 걸친 삽화·배경 길이다(`spreads.jsonl`의 `metrics`).
- `layout.jsonl`: 쪽마다 삽화·사진(크기별), 반복 아이콘·배경(`asset_id`), 색 상자, 코너 이름·제목의 위치(쪽 크기 대비 0~1).
- `design_catalog.json`: 한 권 안에서 3쪽 이상 반복되는 그림(아이콘·마스코트·템플릿 배경, 썸네일은 `images/assets`), 반복 코너 이름(활동 방법·준비물 등), 글자 모양(글꼴·크기·색별 역할 추정).
- `images/layout/`: 판정 결과와 요소 테두리를 그린 펼침면(파랑=삽화, 분홍=반복 아이콘, 주황=색 상자, 빨강=코너 이름, 보라=제목).
- 스캔본처럼 그림 한 장으로 된 PDF는 요소를 나눌 수 없다.

## 처리하지 못하는 파일

- `.LDH`(문서보안 DRM) 파일은 한글에서 열어 HWPX로 다시 저장한 뒤 넣는다.
- 펼침면 단위로 저장된 PDF(한 쪽에 두 면)는 쪽을 나누지 않고 보고서에 표시만 한다.

## 설정

설정은 `preprocessor/settings.json`에 저장된다(Git 제외).

| 항목 | 기본값 |
|---|---|
| 저장 위치 | `official-data/processed` |
| 이미지 | 표준 1100px |
| OCR | 켜짐 |
| 검증 후 원본 | 휴지통으로 이동 |
