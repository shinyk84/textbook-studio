# 교과서 제작 스튜디오

초등 체육 3~6학년 교과서 제작 웹서비스의 1~5단계입니다.

현재 구현 범위:

- 프로젝트 기본 설정
- 교과서 쪽수와 학년군 시수 규칙
- `../criteria`, `../processed` 공식 자료 자동 연결
- 원본 SHA-256과 전처리 산출물 무결성 확인
- 공식 자료 관리자 검수·메모
- 변경 이력과 다음 단계 준비 상태
- 체육과 성취기준 49개 자동 구조화
- 학년군·영역별 교육과정 분석 초안 편집
- 성취기준 원문 검색과 PDF 근거 쪽수
- 분석 버전 저장과 승인 게이트
- 교과서 개발 방향 3개 안 비교·선택
- 공통 개발 원칙과 5개 집필 정책 편집
- 개발 방향 버전 저장과 이전 단계 승인 연동
- 49개 성취기준의 3~6학년 자동 배분
- 학년별 102차시 실시간 균형 계산
- 성취기준 해설·학년·차시·집중도·순서·배치 근거 편집
- 영역별 차시표와 승인 전 자동 검증
- 공식 교육과정의 14개 세부 영역과 신체활동 예시 계층 구조화
- 영역→대단원, 세부 영역→대단원 부제, 신체활동 예시→중·소단원 기초 연결
- 학년별 내용·종목 선택과 우선순위·현장 실행 가능성 비교
- 시설 조건·안전 위험도·안전 대책·선정 근거 편집
- 선택 결과와 49개 성취기준의 연결 범위 자동 검증
- 내용·종목 선정 버전 저장과 이전 단계 승인 연동
- 목차 구성과 학년별 102차시·108~132쪽 통합 배분
- 단원별 목표·핵심 질문·수업·평가·안전·포용 설계
- 대단원 도입·중단원 본문·소단원 활동 원고 초안 편집
- 공식 기준만 사용하는 독립 자동검증·모의심사
- 6~9단계 AI 재생성·웹 편집·버전 저장·순차 승인 게이트

## 실행

```powershell
cd C:\Users\shiny\OneDrive\Desktop\py\textbook-studio
python app.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다.

또는 탐색기에서 `start-studio.cmd`를 더블클릭하면 서버를 시작하고 브라우저를 자동으로 엽니다.

- 1단계 프로젝트 설정: `http://127.0.0.1:8000/`
- 2단계 교육과정 분석: `http://127.0.0.1:8000/analysis`
- 3단계 교과서 개발 방향: `http://127.0.0.1:8000/direction`
- 4단계 성취기준·차시 배분: `http://127.0.0.1:8000/allocation`
- 5단계 내용·종목 선정: `http://127.0.0.1:8000/content`
- 6단계 목차·쪽수·차시 설계: `http://127.0.0.1:8000/outline`
- 7단계 단원 설계: `http://127.0.0.1:8000/design`
- 8단계 원고 초안: `http://127.0.0.1:8000/manuscript`
- 9단계 자동 검증·모의심사: `http://127.0.0.1:8000/review`

별도 데이터 폴더를 사용할 때는 `TEXTBOOK_DATA_ROOT` 환경 변수를 지정할 수 있습니다.
